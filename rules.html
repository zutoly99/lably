📖 Rules & How It Works

Everything you need to know about using Lably

🧾 Member Profile — What Each Field Means

  • Paid: Total plan payments made (excludes deposit). Example: Plan ₹500, paid ₹300 so far → shows ₹300
  • Remaining: How much is still due for current plan. Example: Plan ₹500, paid ₹300 → shows ₹200
  • Seat: The seat number assigned. Shows 'Not assigned' for temporary members
  • Deposit: One-time security deposit collected at registration. Not part of plan amount
  • Join Date: When member was first registered. Never changes
  • Plan Start: Start date of current billing cycle. Changes on every renewal
  • Plan End: Expiry date of current plan. Changes on every renewal
  • Days Left: Days until plan expires. Shows 'Expired X days ago' if overdue
  • Plan: Subscription duration (1 or 3 months) and total plan price

🧮 How 'Paid' and 'Remaining' are Calculated

  • Paid = All plan payments ever made (deposit NOT included)
  • The system counts total plan payments across all cycles
  • Remaining = Plan price − (total paid in current cycle)
  • Current cycle paid = total paid % (modulo) plan price
  • Example: Plan ₹500. Total paid ₹800. Current cycle: ₹800 % ₹500 = ₹300. Remaining: ₹200
  • Example: Plan ₹500. Total paid ₹1000. Current cycle: ₹0 (fully paid). Remaining: ₹0
  • When remaining = ₹0 AND plan is expired → next payment triggers renewal
  • Deposit is shown separately and never counts toward 'Paid' amount

👥 Member Types

  • Two member types: Fixed (dedicated seat) and Temporary (no fixed seat)
  • Fixed members must have a seat assigned at registration
  • Temporary members cannot have a seat
  • If no seats available, member must be registered as Temporary
  • Temporary members can only have a 1-month plan

💰 Plans & Pricing

  • Fixed members can choose 1-month or 3-month plan
  • Temporary members always have 1-month plan only
  • Plan prices are set in Settings by the library owner
  • 3-month plan price is the total for all 3 months combined

🔄 Plan Switching Rules

  • 1-month → 3-month: Allowed anytime (upgrade)
  • 3-month → 1-month: Only allowed after plan expires
  • 3-month → 1-month while active: NOT allowed
  • 3-month fixed → Temporary: NOT allowed (ever)
  • 1-month fixed → Temporary: Allowed (seat will be freed)
  • Temporary → Fixed: Allowed (must assign a seat)
  • On plan change, pricing auto-updates from library settings

🔒 Deposit

  • Deposit is collected only once at the time of registration
  • Deposit is NOT charged on renewals — only first time
  • When a member pays at registration, deposit is deducted first, remaining goes to plan
  • Set deposit to ₹0 in Settings to disable it

💳 Payments & Due

  • Payment clears previous due first, then goes to new plan
  • If member pays less than full amount, remaining is shown as 'Due'
  • Plan auto-renews only when full plan amount is paid AND plan is expired
  • Active members paying partial: no renewal triggered, just reduces due
  • If member is active and fully paid, no payment needed until expiry
  • Duplicate phone/email not allowed for active members in same library

📝 How to Record Payment

  • Go to member detail → tap 'Record Payment'
  • If member is ACTIVE with due: amount auto-fills with due amount only
  • If member is EXPIRED: amount auto-fills with due + plan price (full renewal)
  • You can change the amount to whatever the member actually paid
  • Payment date: defaults to today, change if payment was received earlier
  • Plan Start Date: only shown when renewal will happen (defaults to expiry + 1 day)
  • If member is going away, set a future Plan Start Date (e.g., comes back after 10 days)
  • After recording, PDF receipt is auto-generated and can be shared via WhatsApp
  • Split calculation shows clearly: money goes to clear due first, then to new plan

📊 Revenue Calculation

  • Revenue is calculated based on actual payment received date
  • If payment received in June → counted in June revenue
  • Monthly revenue = all payments received from 1st to end of that month
  • Revenue includes deposits collected (it's cash received)

📱 WhatsApp Message Rules

  • Send from member detail page → 'WhatsApp Message' button
  • Message content auto-changes based on member's expiry status:
  •   • Expired: Urgent renewal reminder with amount due and UPI details
  •   • Expiring within 8 days: Warning with renewal details
  •   • Active: General greeting using your custom template
  • Message includes: library name, member name, expiry date, amount, UPI ID
  • If QR code is uploaded, option to share QR image for payment
  • Custom template can be set in Settings (variables: {name}, {amount}, {expiry}, {library}, {upi_id})
  • 'Send Last Receipt' shares the latest PDF receipt link via WhatsApp
  • Member must have a phone number saved to send WhatsApp messages

🔁 Renewal Rules

  • Plan renewal only triggers when the plan is expired AND full payment received
  • If plan is active, payments only clear due — no renewal triggered
  • Plan Start Date defaults to expiry date + 1 day
  • Library owner can set a custom Plan Start Date (e.g., member is away)
  • Plan End Date = Plan Start Date + (30 × subscription months)
  • Join Date never changes — Plan Start and Plan End change on every renewal
  • Partial payment (not enough for renewal) reactivates member but doesn't extend dates

💺 Seat Rules

  • Each seat can only be assigned to one member at a time
  • Fixed members must have a seat assigned at registration
  • If no seats available, must register as Temporary
  • When member is deactivated/deleted/converted to Temporary, seat is freed
  • Total seats can be changed in Settings
  • Cannot reduce seats below the number currently occupied

⏸️ Deactivation & Reactivation

  • Deactivating a member frees their seat and marks them inactive
  • Inactive members cannot make payments or perform actions
  • Reactivating restores the member to active (seat must be re-assigned manually)
  • Deleting a member permanently removes them and frees their seat

  • Inactive members cannot make payments or perform actions
  • Reactivating restores the member to active (seat must be re-assigned manually)

📋 Library Subscription

  • Library must have an active subscription to add/manage members
  • If library subscription expires, member operations are blocked
  • Library subscription is managed by the platform admin

⚡ Quick Reference

  • ✅ Fixed 1-month → 3-month: Always allowed
  • ✅ Fixed 1-month → Temporary: Allowed
  • ✅ Temporary → Fixed: Allowed
  • ✅ 3-month → 1-month: Only when expired
  • ❌ 3-month → Temporary: Never allowed
  • ❌ 3-month → 1-month while active: Not allowed
  • ❌ Add Fixed member if no seats: Not allowed
  • ❌ Duplicate phone/email for active members: Not allowed
